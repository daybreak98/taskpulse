# TaskPulse 安装指南

TaskPulse 是贴在屏幕边缘的一条细条，点开能看到你所有 DataAgent 会话的状态。装完之后它会一直待在屏幕右侧，不需要你手动启动。

整个安装只需要三步，其中只有装浏览器扩展需要你动手点两下，其余都是自动的。

---

## 第一步：卸载旧版本（第一次装可跳过）

如果你之前装过 TaskPulse，先双击打开 `uninstall.command`。它有两个位置，哪个方便用哪个：

- 刚解压出来的文件夹里（`TaskPulse-日期-internal/uninstall.command`）
- 已经装过的机器上：`~/Applications/TaskPulse/uninstall.command`

窗口跑完会显示「已卸载」。它会把旧的 App 和后台服务都清掉，但**保留**你的任务历史（在 `~/.taskpulse` 里）。想彻底从零开始，先在终端执行 `rm -rf ~/.taskpulse` 再卸载。

装完旧版本残留没清，新装可能起两个窗口。所以升级时这一步不要省。

---

## 第二步：安装

1. 双击解压出来的文件夹 `TaskPulse-日期-internal`
2. 双击里面的 `install.command`

> 如果系统提示「无法打开，因为来自身份不明的开发者」，**右键点它 → 选「打开」→ 再点「打开」**。只需要这一次。

然后会弹出一个终端窗口自己跑，大约 30 秒（第一次要联网装依赖）。中途不需要你输入任何东西。

**跑完你应该看到**最后一行类似：

```
结论：就绪（端口 8899，采样于 3 秒前，...）（退出码 0）
```

如果看到的是「服务在线，但取数还没就绪」——先不用管，那是扩展还没装，下一步装完就会好。

同时屏幕右下角会弹出一个引导窗口，带你装浏览器扩展。

---

## 第三步：装浏览器扩展（唯一需要动手的地方）

引导窗口会让你选浏览器，**选 Edge**（你的 DataAgent 页面都在 Edge 里）。

选完之后，它会自动帮你做三件事：

- 打开浏览器的扩展管理页
- 把扩展目录的路径复制到剪贴板
- 在访达（Finder）里选中那个目录，方便你拖拽

你只需要在扩展页里做两件事：

1. 打开页面右上角的 **开发人员模式** 开关
2. 点 **加载解压缩的扩展**，在弹出的选择框里选中已经高亮好的 `edge-ext` 文件夹，点「选择」

装好后引导窗口会自己变成「已连接」，不需要点任何检查按钮，直接关掉就行。

> 引导窗口不小心关掉了？右键点屏幕边上的细条 →「重新打开安装引导」。

### 两个浏览器都用怎么办

扩展可以同时装进 Edge 和 Chrome，互不影响，也不会重复取数。做法就是在另一个浏览器的扩展页里**重复上面那两步**，选的是**同一个 `edge-ext` 目录**（路径在引导窗口里，点「再复制一次」就有）。

之后哪个浏览器开着 DataAgent 标签，TaskPulse 就认哪个；点任务会切到「这个会话所在的那个浏览器」里的标签。

---

## 第一次使用

**1. 切到 WEB 模式**

展开细条（点一下它），表头右侧有个 `API` / `WEB` 的小开关，点 `WEB`。

> 两种模式的区别：`WEB` 用你浏览器里已登录的账号取数，不需要任何配置；`API` 需要本机有内网凭据。日常用 `WEB` 就行。

**2. 授权跳转**

第一次点任务行时，系统会问「TaskPulse 想要控制 Microsoft Edge」，点**允许**。之后点任务就能直接跳到对应的对话标签页。

**3. 记住留一个页面开着**

`WEB` 模式需要浏览器里至少有一个 DataAgent 页面开着。多个页面都开着也可以，但只有其中一个负责取数，其余的不会重复请求。

---

## 日常使用

- **点任务行**：跳到对应的对话标签页
- **点数字**：只看这一类（运行中 / 等你回复 / 卡住），再点一次取消
- **勾选框**：把任务标记为已处理
- **图钉**：固定展开，不用每次点开
- **右上角的叉**：退出浮窗（悬停会变红）
- **双击细条**：展开 / 收起

退出之后想再用，双击 `~/Applications/TaskPulse.app` 就能打开，后台取数一直在跑，打开就有数据。重启电脑也会自动出现。

---

## 状态说明

| 状态 | 含义 |
|---|---|
| 运行中 | agent 正在处理 |
| 等你回复 | agent 说完了，等你下一步指令 |
| 卡住 | 超过 30 分钟没有进展，或最后一条消息提到限流 |
| 已查看 | 你已经看过了，不再计数 |
| 完成 | 你手动勾选标记为处理完毕 |

偶尔会在右上角看到一条提示条（新回复 / 卡住 / 超时），点它直接跳过去，15 秒后自动消失。安装时**不会**因为历史任务补弹一堆提醒。

如果看到「N 个会话状态待确认」，意思是这几个会话在这一轮没取到状态，数字先别当真，下一轮会自己恢复。

---

## 分组（标签组名）是怎么来的

分组名是**浏览器扩展**读到的标签组名，和取数模式无关——`API` 也好 `WEB` 也好，都一样。

- 只有「浏览器里开着标签」的会话才显示分组，没开的显示「未分组」
- **全部显示「未分组」，基本就是扩展没连上**：扩展被浏览器禁用了，或者装在了另一个浏览器里
- 想确认扩展在不在：在浏览器里开一个 DataAgent 页面，看引导窗口（右键细条 → 重新打开安装引导）是否显示「已连接」

## API 模式取不到数据？

`API` 模式是进程直连接口，需要本机**先完成一次扫码授权**（用快手 App 扫，约 30 秒）。
授权一次之后长期可用；会话过期时重跑决定一次即可。

操作只有一个：

1. 双击 `api_login.command` → 屏幕上会打开一个浏览器窗口，里面就是登录页和二维码
   → 用手机上的快手 App 扫码
2. 再双击 `api_check.command` 确认

如果窗口没出现（少数环境只允许后台运行），改用 `api_login.command --terminal`，
二维码会直接画在终端里。

那个浏览器窗口用的是独立配置目录，不影响你平时浏览器的登录状态。

如果暂时不想授权，用 `WEB` 模式，它用浏览器里的登录态，不需要任何授权。

## macOS 提示「TaskPulse 在后台运行」

这条不是 TaskPulse 自己发的（程序里没有任何系统通知调用），是 macOS 对
「后台项目」的提醒：它发现有两个 launchd 项目在常驻。

它们已经声明了归属（`AssociatedBundleIdentifiers`），系统设置里会归到
TaskPulse 名下。要让它安静下来：

1. 打开「系统设置」→「通用」→「登录项与扩展」
2. 在「允许在后台」里找到 TaskPulse，确认它是打开状态

之后系统不会再反复提示。只要不重新安装，这个状态会一直记住。

## 遇到问题

**细条没出现**

打开「活动监视器」，搜索 TaskPulse，看有没有进程。没有的话双击 `~/Applications/TaskPulse.app`。

**数字一直不动**

1. 确认浏览器里至少开着一个 DataAgent 页面
2. 确认扩展页里 TaskPulse Tab Bridge 是开启状态
3. 展开细条，看顶部有没有黄色提示条——上面会写原因

**点任务没反应**

第一次点击需要允许控制浏览器。如果误点了「不允许」，打开「系统设置 → 隐私与安全性 → 自动化」，把 TaskPulse 对 Microsoft Edge 的开关打开。

**想彻底删干净**

1. 双击 `uninstall.command`
2. 浏览器扩展页里移除 TaskPulse Tab Bridge
3. `rm -rf ~/.taskpulse`
