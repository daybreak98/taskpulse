# TaskPulse · 使用说明

贴在屏幕右边缘的一条细条，点开能看到你所有 DataAgent 会话的状态。
**不需要终端、不需要预装 Python，装完不常驻后台。**

---

## 第一次用（3 步）

### 1. 双击 `TaskPulse.app`

系统可能提示「无法打开」或「无法验证开发者」——这是 macOS 对个人签名应用的标准拦截。

任选一种放行：

- 在 `TaskPulse.app` 上**右键 → 打开**
- 或双击一次被拦后，去「系统设置 → 隐私与安全性」，滚到底部，点 **「仍要打开」**，输入开机密码

只需要放行这一次。

### 2. 等它自己准备

App 打开后会显示「正在准备运行环境」，一步一步往下走，通常十几秒（第一次要连内网装依赖会久一点）。

不需要你做任何事。如果某一步失败，窗口里会写明卡在哪，处理好后点「重试」即可。

### 3. 装浏览器扩展

准备完成后，窗口会带你装扩展：

1. 选你平时看 DataAgent 的浏览器（Edge 或 Chrome）
2. 它会自动打开扩展页、把扩展目录路径复制到剪贴板
3. 在扩展页右上角打开「开发人员模式」
4. 点「加载解压缩的扩展」→ 选中窗口里显示的那个目录 → 「选择」

装好后窗口会自己变成「已连接」。

> 要选的是 `~/Applications/TaskPulse/edge-ext`（窗口里显示的路径），
> 不是你解压 zip 的那个文件夹。

---

## 之后怎么用

| 操作 | 效果 |
|---|---|
| 双击 `TaskPulse.app` | 打开细条并开始取数 |
| 点细条 | 展开列表 |
| 点任务行 | 跳到对应的浏览器标签 |
| 点数字 | 只看那一类，再点取消 |
| 点右上角的叉 | **彻底退出**：浮窗和取数一起停，不留后台进程 |

**不会开机自启。** 想用的时候打开一次；关掉就完全停止。

---

## 取数模式

顶部有 `API` / `WEB` 开关：

- **WEB**（默认）：用浏览器里已登录的账号取数，浏览器里要开着至少一个 DataAgent 页面
- **API**：本机直连接口，更快、不用开页面，但需要先扫码授权一次

API 凭据过期时，展开小窗会看到「API 凭据已失效」和一个「扫码重新授权」链接，点它扫码即可。

---

## 数据与隐私

- 只读标签标题、URL、标签组名，以及平台接口返回的会话状态
- 「是否限流」的关键词匹配在页面内完成，只留一个「是 / 否」，消息原文不外传
- 数据只写在本机 `~/.taskpulse/`，不上传到任何服务器

---

## 出问题了

| 现象 | 处理 |
|---|---|
| 双击没反应 | 右键 → 打开；仍不行去「隐私与安全性」点「仍要打开」 |
| 一直停在「正在准备运行环境」 | 看窗口里最后一步；多半是没连内网（装依赖要走内网源），连上后点「重试」 |
| 细条不见了 | 再次双击 `TaskPulse.app` |
| 数字不动 | 确认浏览器里开着 DataAgent 页面、扩展是启用状态 |
| 想彻底删掉 | 运行 `~/Applications/TaskPulse/uninstall.command`，再在扩展页移除 TaskPulse |
