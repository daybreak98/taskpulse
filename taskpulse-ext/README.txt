TaskPulse 网页版 2.1.1
=====================

安装
----
1. 解压，保留 taskpulse-ext 文件夹。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启「开发人员模式」，点「加载解压缩的扩展」，选择含 manifest.json 的 taskpulse-ext。
4. 在这个浏览器中打开并登录 DataAgent。已经打开的页面通常会自动出现胶囊，必要时刷新一次。

使用
----
- DataAgent 页面右上方的竖排胶囊沿用桌面版的蓝、琥珀、珊瑚三种状态色，依次对应运行中、待处理、疑似卡住。
- 悬停展开玻璃面板，移开收起。点图钉保持展开，点数字筛选，双击标题栏空白处可展开或折叠分组。
- 拖动竖排胶囊或展开面板标题栏空白处可以调整位置，位置保存在当前浏览器，并在各网页间同步。
- 顶部 DA / TAB 分段按钮分别选择 DataAgent 内部分组、浏览器原生标签组。TAB 只展示浏览器中已经打开的 DataAgent 会话，未分组的真实标签归入「未分组标签页」，不读取 DataAgent 分组作为兜底。同会话多个标签只显示一行。
- 面板与胶囊计数默认仅展示最近 24 小时有真实活动、且未被勾选移除的会话。采集和已排队通知的既有可靠性策略不变。
- 面板底部「显示设置」可恢复位置、开启全网页显示。首次开启需在浏览器授权普通 HTTP/HTTPS 网页访问；关闭时撤销可选权限。
- 点会话行可直达对应标签，标签没有打开时会新开一个。会话行右侧可标记本轮已处理。
- 新回复会发系统通知。开启全网页显示后，前台获授权的普通网页也有桌面版样式的右上角提示条，点击直达对应会话。前台已经在查看该会话时自动标记已查看，历史回复静默初始化。
- 在系统通知设置中允许 Chrome 或 Edge 发送通知。请保留至少一个已登录的 DataAgent 页面供采集。
- 普通网页或浏览器特殊页面点工具栏图标可打开原生侧栏（浏览器支持时）。侧栏提供同样的分组切换、状态和会话跳转。受保护页面或禁止嵌入的网页可能无法显示悬浮胶囊，仍可用侧栏和系统通知。

工作范围
--------
由 DataAgent 网页自己的登录状态取数，整个浏览器仅一个采集者。活跃会话队列约 2 秒、活跃期间列表约 5 秒，
完成后短时间快速复查最新消息，确认后退回低频。普通会话列表约 30 秒、空闲队列约 60 秒。
每 2 秒的滑动窗口最多 12 个请求；每轮最多查 6 个队列。无状态变化时避免高频状态写入。
后台活跃采集者由扩展 Worker 尝试主动唤醒。浏览器冻结、系统休眠、网络及服务端更新延迟仍会影响实际可见时间。
目前以网页操作/路由变化提示和自适应轮询为主，尚未接入真实 DataAgent 的服务器推送协议。
至少保留一个已登录的 DataAgent 页面。退出登录或取数失败时显示待确认，恢复后重新核验。

同一个浏览器里优先只启用一种 TaskPulse 扩展。若与桌面版的浏览器桥接扩展同时开启，
两套 WEB 采集会分别向 DataAgent 请求。

数据保存在当前浏览器。全网页模式使用扩展来源隔离界面展示任务数据；普通网页宿主只管理显示尺寸、位置和交互，不接收任务标题或消息内容。系统通知使用会话标题。最新消息的失败关键词在页面中匹配，
保存的是发送方类型、标记和版本等状态字段。浏览器的扩展管理页可移除扩展。


低负载采集（候选）
------------------
已成功核验、列表版本未变、已查看且未打开的会话，每 5 分钟抽查队列及消息。
运行、等待回复、未读、已打开及证据不完整的会话保持原采集策略；发现列表版本变化或网页操作会重新提升优先级。
冷会话的旧观测不会冒充新鲜数据，若服务端列表时间不变且没有网页操作，发现变化可能等到下一次抽查。
HTTP 429、带 Retry-After 的 503、明确过载响应或连续两次服务端/网络超时失败触发采集全局退避；尊重 Retry-After，默认从 30 秒指数退避并加随机抖动。
暂停期间不会继续查其他会话，切换采集页也继承暂停。该机制仅约束本浏览器的 TaskPulse 请求，不限制 DataAgent 原生请求或其他用户。

原生网页复用调研采用被动 Resource Timing 观察器：不改写 fetch/XHR，不读取原生响应正文、不读取凭证、不上传指标、不新增服务端请求或浏览器权限。
在扩展 Service Worker 的开发者工具中，可用 chrome.tabs.sendMessage(tabId, {kind:"tp.probe"}, {frameId:0}) 查看每个 DataAgent 页面 nativeObservation 的聚合计数。
native 表示成功的同源目标接口观察，unknownStatus 表示浏览器没有提供可核实 HTTP 状态，own 是当前页插件自己的请求次数，possibleOverlap 是两秒内同接口/会话的潜在重叠（请求参数和账号范围仍需确认）。
当前只观测覆盖情况，不把原生网页数据直接用于新回复或已读确认，也不据此声称已消除重复请求。真实 DataAgent 兼容性需要现场验证。
