TaskPulse 网页版 2.1.0
=====================

安装
----
1. 解压，保留 taskpulse-ext 文件夹。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启「开发人员模式」，点「加载解压缩的扩展」，选择含 manifest.json 的 taskpulse-ext。
4. 在这个浏览器中打开并登录 DataAgent。已经打开的页面通常会自动出现胶囊，必要时刷新一次。

使用
----
- DataAgent 页面右上方的蓝、金、粉数字分别对应运行中、待处理、疑似卡住。
- 点数字筛选，点左侧图标展开全部会话。点一行会切到已打开的会话，没有对应标签时会新开一个。
- 新回复会出现在系统通知里。点通知也能直达会话。首次接入的历史回复会静默初始化。
- 在系统通知设置中允许 Chrome 或 Edge 发送通知。请保留至少一个已登录的 DataAgent 页面供采集。
- 浏览器工具栏的 TaskPulse 图标也可以打开 DataAgent。

工作范围
--------
由 DataAgent 网页自己的登录状态取数，只需浏览器扩展。采样间隔沿用 WEB 模式，
会话列表约 30 秒，活跃队列约 5 秒，空闲队列约 60 秒。实际可见时间受浏览器节流和请求耗时影响。
页面休眠或退出登录时，胶囊会显示状态待更新。重新登录或唤醒页面后会继续采集。

同一个浏览器里优先只启用一种 TaskPulse 扩展。若与桌面版的浏览器桥接扩展同时开启，
两套 WEB 采集会分别向 DataAgent 请求。

数据保存在当前浏览器。系统通知使用会话标题。最新消息的失败关键词在页面中匹配，
保存的是发送方类型、标记和版本等状态字段。浏览器的扩展管理页可移除扩展。
