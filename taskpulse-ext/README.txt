TaskPulse（浏览器扩展版）
========================

不用安装 App、不用终端、不用 Python。整个产品就是一个扩展。

安装（两次点击）
----------------

1. 解压这个 zip，得到一个 taskpulse-ext 文件夹（放在哪里都行，别删）
2. 浏览器地址栏打开：
     Edge   → edge://extensions
     Chrome → chrome://extensions
3. 右上角打开「开发人员模式」
4. 点「加载解压缩的扩展」→ 选中 taskpulse-ext 文件夹 → 选择

装好后浏览器工具栏会多一个 TaskPulse 图标。点它，右侧会打开侧边栏。

第一次用需要先有数据
--------------------

扩展的数据来自你打开的 DataAgent 页面（用你自己的登录态，不需要任何授权）。

- 打开一个 DataAgent 会话页，并保持它开着
- 侧边栏 30 秒内会开始显示会话列表
- 如果显示「还没有数据」，把 DataAgent 页面刷新一次（F5），让扩展注入进去

能做什么
--------

- 看所有会话：运行中 / 等我回复 / 卡住（超过 30 分钟没进展）
- 点一行 → 切到那个会话的标签；标签关了就在新标签打开
- 点行尾的 ✓ → 标记处理完毕，从列表消失
- 点顶部三个计数 → 只看那一类，再点一次取消
- 按浏览器标签组名分组

有什么限制
----------

1. **只能在浏览器里看**，不是屏幕边缘那个常驻小窗。切到别的 App 就看不到。
2. **必须开着至少一个 DataAgent 页面**，所有数据都从它取。
3. 没有 API 模式（那个需要本机进程，扩展做不到）。

数据与隐私
----------

- 只读：标签标题、URL、标签组名，以及平台接口返回的会话状态
- 「是否限流」的关键词匹配在页面内完成，只留一个「是/否」
- 数据只存在本机的 chrome.storage.local，除 DataAgent 自己的接口外不发往任何地方
- 不读取页面正文，不读取聊天记录全文

卸载
----

扩展页 → TaskPulse → 移除。数据随扩展一起清掉。
