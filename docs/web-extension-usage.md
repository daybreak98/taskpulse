# TaskPulse 网页版 · 使用说明

贴在 DataAgent 页面右上角的一组小胶囊，用来一眼看清所有会话的状态。
**不装 App、不需要终端、不需要 Python。**

---

## 安装（浏览器里 3 步）

1. 解压 `TaskPulse-ext-<日期>.zip`，保留 `taskpulse-ext` 文件夹（放哪都行，别删）
2. 地址栏打开扩展页：

   | 浏览器 | 地址 |
   |---|---|
   | Edge | `edge://extensions` |
   | Chrome | `chrome://extensions` |

3. 打开右上角「开发人员模式」→ 点「加载解压缩的扩展」→ 选 `taskpulse-ext` 文件夹

装好后地址栏右侧会出现 TaskPulse 图标。**打开（或刷新）一个 DataAgent 页面**，胶囊就会出现。

> 需要 Chrome / Edge **120 以上**。

---

## 怎么用

| 操作 | 效果 |
|---|---|
| 看右上角竖排胶囊 | 三个数字：蓝 = 运行中、琥珀 = 等我回复、珊瑚 = 疑似卡住 |
| 鼠标悬停 | 展开玻璃面板 |
| 移开鼠标 | 自动收起 |
| 点图钉 | 固定展开，不用反复悬停 |
| 点某个数字 | 只看那一类，再点一次取消 |
| 双击标题栏空白处 | 全部分组展开 / 折叠 |
| 点会话行 | 跳到那个会话的标签（没开就新开一个） |
| 点行右侧 ✓ | 标记本轮已处理，从列表移除 |
| 点通知 / 提示条 | 直接跳到对应会话 |

新回复会发**系统通知**，前台页面还会弹一条同款提示条；历史回复不会补弹。

---

## 三个前提

1. **至少保留一个已登录的 DataAgent 页面**——所有数据都从它取，页面关掉就没有数据
2. **允许通知**：系统设置 → 通知 → 找到 Edge / Chrome → 允许
3. 第一次装完要**刷新一次页面**（让脚本注入）

---

## 和桌面版的差别

| | 网页版（本方案） | 桌面版 |
|---|---|---|
| 安装 | 加载扩展，无系统拦截 | 双击安装器，要放行一次 |
| 体积 | 28 KB | 72 MB |
| 位置 | 只在 DataAgent 页面内 | 屏幕边缘，切到任何 App 都看得见 |
| 取数 | 页面同源接口（要开页面） | 页面 或 本机接口（可不开页面） |
| 适合 | 快速试用、不想装 App | 主力日常使用 |

两者可以同时装，但**不要同时启用**——会在同一个页面重复采集。

---

## 卸载

扩展页 → TaskPulse → 「移除」。数据随扩展一起清掉。

---

## 常见问题

| 现象 | 处理 |
|---|---|
| 页面里没有胶囊 | 先刷新页面；再看扩展页里 TaskPulse 是否是启用状态 |
| 数字一直是 0 | 确认这个页面已登录，且只有一个页面负责采集（其余页面会自动让位） |
| 收不到通知 | 系统设置 → 通知 → 允许 Edge / Chrome |
| 回复后要等一会儿才更新 | 采集页在后台时 Chrome 会把定时器限流到分钟级，我们靠 30 秒一次的 alarm 唤醒，所以最坏约 30 秒。面板里会写「数据 N 秒前」。把 DataAgent 页面切到前台可恢复到 2–5 秒 |
| 点会话没跳转 | 确认标签还在；会话标签被关掉时会新开一个 |
| 想换成桌面版 | 先移除这个扩展，再装桌面版（避免重复采集） |
