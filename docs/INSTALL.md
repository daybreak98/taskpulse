# TaskPulse 安装步骤

TaskPulse 是贴在屏幕右边缘的一条细条，点开能看到你所有 DataAgent 会话的状态：
谁在跑、谁在等你、谁卡住了。点一下任务就跳到对应的浏览器标签。

全程大约 **5 分钟**，其中需要你动手的只有「装浏览器扩展」这一步。

---

## 开始之前

| 需要 | 说明 |
|---|---|
| macOS 13 或更新 | Intel / Apple Silicon 都可以 |
| 一个 Chromium 内核浏览器 | Edge 或 Chrome，**用你平时看 DataAgent 的那个** |
| 能打开 DataAgent 网页 | 也就是你平时干活的账号能正常登录 |
| 能连公司网络 | 装依赖时要从内网源取一个 Python 包 |

**不需要**：管理员密码、Node/npm、Git、命令行操作、事先装 Python。
安装包自带 uv 和 Python 运行时。

---

## 第一步：解压

双击 `TaskPulse-日期-internal.zip`，得到同名文件夹。

> 别在压缩包里直接双击脚本。`install.command` 需要同目录下的
> `TaskPulse.app`、`poller.py`、`edge-ext`、`vendor`、`config.json`。

---

## 第二步：双击 `install.command`

### 双击被系统拦下来怎么办

提示可能是「无法验证」「无法打开」「来自身份不明的开发者」「Apple 无法检查是否包含恶意软件」——
都是同一件事：macOS 对「从网上下载、没有苹果签名」的脚本的统一拦截，不是 TaskPulse 的问题。

三种办法，任选一种：

**① 右键打开（最快）**

在 `install.command` 上右键 → 选「打开」。有时会在弹窗里再点一次「打开」。

**② 系统设置里放行**

1. 先双击一次 `install.command`（让它被拦截）
2. 打开「系统设置 → 隐私与安全性」，往下滚到「安全性」区域
3. 会出现「已阻止使用 install.command，因为来自身份不明的开发者」→ 点 **「仍要打开」** → 输入开机密码

这个按钮只在被拦截后一小时内出现，所以顺序不能颠倒。

**③ 终端一行（最保险，一定管用）**

打开「访达」→ 前往 `~/Downloads`，找到解压出来的文件夹，右键文件夹 →
「服务」→「新建位于文件夹位置的终端窗口」，然后粘贴：

```bash
xattr -dr com.apple.quarantine . && ./install.command
```

或者直接在「终端」里（路径换成你的实际解压位置）：

```bash
cd ~/Downloads/TaskPulse-20261125-internal
xattr -dr com.apple.quarantine . && ./install.command
```

`xattr` 那一步只清理「下载」标记，不涉及权限；终端里运行的脚本不会被 Gatekeeper 拦。

然后会弹出一个终端窗口自己跑。

### 它在这几十秒里做了什么

1. 检查本机有没有能用的 `uv` 和 Python
   - 有 → 直接用，一个字节都不装
   - 没有 → 解压安装包自带的（uv 27MB + Python 80MB）
   - 有但坏了 → **弹窗说明原因**，你选「用安装包自带的」或「先不装了」
2. 从内网源安装取数依赖 `ks-aimate`
3. App 装到 `~/Applications/TaskPulse.app`，扩展目录装到 `~/Applications/TaskPulse/edge-ext`
4. 生成一份本机密钥，只存在 `~/.taskpulse/token`（权限 0600），扩展和 App 共用
5. 注册两个开机自启项，拉起小窗
6. 跑一次健康检查

### 你应该看到的输出

```
== TaskPulse 安装 ==
-- 用本机已有的 uv：/Users/you/.local/bin/uv（uv 0.13.10 ...）
-- 用本机已有的 Python：/Users/you/.local/share/uv/python/.../python3.15
-- 使用安装包内自带的配置：/Users/you/.taskpulse/config.json
-- 端口: 8899    扩展域名: https://dataagent.corp.kuaishou.com/*
-- 检查运行依赖（从内网源装 ks-aimate，首次约 10-40 秒）...
   -> 依赖就绪
-- 已生成本机接口密钥：/Users/you/.taskpulse/token
   -> manifest.json / config.js
   结论：就绪（端口 8899，采样于 3 秒前，...）（退出码 0）
```

耗时：**10 秒–40 秒**。本机什么都没有、要从包里解压运行时，实测冷启动 7.4 秒。
走了在线下载的机器 2–4 分钟。

**装完的判定标准**：最后一行出现 `结论：就绪 ... （退出码 0）`。

看到 `服务在线，但取数还没就绪` 是正常的——扩展还没装，下一步装完就好。

### 取数服务什么时候跑

**打开 App 就开始取数，关掉就停**，不注册任何开机自启项：

- 系统设置的「允许在后台」里不会出现 TaskPulse，也不会有「后台项目」提示
- 没打开 App 的时候，机器上没有任何 TaskPulse 进程在跑
- 开机后不会自动出现，要用时双击 `~/Applications/TaskPulse.app`

安装脚本最后会自动帮你打开一次 App——那是为了让你看到扩展引导。

## 第三步：装浏览器扩展（唯一需要动手的地方）

安装快结束时，屏幕中间会弹一个引导窗口。

### 3.1 选浏览器

**选你平时看 DataAgent 的那个**（通常是 Edge）。

窗口会自动做三件事：打开那个浏览器的扩展管理页、把扩展目录路径复制到剪贴板、
在访达里把 `edge-ext` 文件夹选中。

### 3.2 你只需要两步

1. 扩展页右上角，打开 **开发人员模式**
2. 点 **加载解压缩的扩展** → 选中已经高亮好的 `edge-ext` 文件夹 → 「选择」

> 拖拽方式也行：把访达里选中的 `edge-ext` 直接拖进扩展页中间的空区域。

**⚠️ 最容易选错的地方**：要选的是 `~/Applications/TaskPulse/edge-ext`（引导窗口里显示的那个路径），
**不是**解压包里的、也不是 Kim / 下载目录里的那份。那两份只有模板文件，没有 `manifest.json`，
加载会报「清单文件缺失或不可读取」。

引导窗口里会**完整显示**扩展目录路径（可选中复制），方便你在文件选择框里逐级找：

```
/Users/你的用户名/Applications/TaskPulse/edge-ext
```

旁边有三个按钮：**再复制一次**、**在 Finder 里选中**、**重新打开扩展页**。

### 3.3 判定装好了

装好后引导窗口会**自己变成「已连接」**，不需要点检查按钮。

一直显示「正在检测扩展上报…」的话：

- 确认加载的是 `~/Applications/TaskPulse/edge-ext`（不是解压包/Kim 缓存里那份）
- 确认扩展在扩展页里是「已启用」（不是灰的）
- 确认这个浏览器里**开着至少一个 DataAgent 会话页面**
- 仍不行就点「重新打开扩展页」，点扩展卡片上的 ⟳ 重新加载一次

### 3.4 两个浏览器都想用

扩展可以同时装进 Edge 和 Chrome，不会重复取数，也不会互相干扰。
在另一个浏览器的扩展页里**重复 3.2 那两步**，选的是**同一个 `edge-ext` 目录**。

之后点任务会切到「这个会话所在的那个浏览器」里的标签。

## 第四步：选数据来源

展开细条，表头右侧有个 `API` / `WEB` 开关。

| 模式 | 怎么取数 | 什么时候用 |
|---|---|---|
| `WEB` | 用浏览器里已登录的账号取 | **默认推荐**，不需要任何配置 |
| `API` | 本机进程直连接口 | 需要本机先完成一次扫码授权 |

`WEB` 要求浏览器里至少开着一个 DataAgent 页面；全关掉后界面会提示「页面没有上报数据」。

### 4.1 API 模式需要一次扫码授权

`API` 模式需要本机有一份登录凭据，**必须是本人授权产生的**，所以要扫码一次。

扫码的作用与边界（终端里也会先打印一遍）：

| | |
|---|---|
| 做什么 | 把一份「你本人授权」的凭据写到本机 `~/.codeflicker/sso/`，一次授权长期可用 |
| 不做什么 | 不读取、不接管你的浏览器，不拿网页内容，也不碰浏览器里的 cookie |
| 不做什么 | 不接触手机上的数据（扫码只做身份确认，不会装任何东西） |
| 不做什么 | 凭据只存在本机，不上传到任何地方 |

操作步骤：

1. 双击 `~/Applications/TaskPulse/api_login.command`
2. 屏幕上会打开一个浏览器窗口，里面是登录页和二维码
3. 用手机上的快手 App 扫码授权
4. 授权成功后自动验证取数

二维码约 1 分钟有效。那个浏览器窗口用独立配置目录，不影响你平时的登录状态。

**跳过也没关系**：一直用 `WEB` 模式即可，功能一样，只是要求页面开着。

### 4.2 凭据失效了怎么办

凭据过期时，小窗展开后的黄条会写「API 凭据已失效，取数已暂停」，下面出现一个
**扫码重新授权**的链接——点它就会走一遍同样的扫码流程，不用自己去找脚本。

这个按钮只在真的 401 时出现，日常使用不会占位。

## 自检清单

| 检查项 | 怎么看 |
|---|---|
| 小窗出现了 | 屏幕右边缘的一条细条 |
| 进程在跑 | 活动监视器里搜 `TaskPulse`，应有 2 个进程 |
| 扩展连上了 | 引导窗口显示「已连接」，或 `/state` 里 `extension.ok` 为 `true` |
| 取数正常 | 点开细条，数字在变；`poller_error` 为 `null` |
| 分组正常 | 开了标签的会话显示标签组名，没开的显示「未分组」 |
| 点任务能跳 | 第一次会问「TaskPulse 想要控制 Microsoft Edge」，点允许 |

看原始状态：

```bash
curl -s -H "X-TP-Token: $(cat ~/.taskpulse/token)" http://127.0.0.1:8899/state
```

## 日常使用

- **点任务行** → 跳到对应会话的标签页（不会新开）
- **点数字** → 只看那一类（运行中 / 等你回复 / 卡住），再点一次取消
- **勾选框** → 这个任务处理完了，从列表移除
- **图钉** → 固定展开，不用每次点开
- **右上角的叉** → 彻底退出（悬停变红）：浮窗和取数一起停，不留后台进程
- **打开 App** → 双击 `~/Applications/TaskPulse.app`，取数立刻开始，不用等配置
- **双击细条** → 展开 / 收起
- **右键细条** → 重新打开安装引导

## 权限与数据

| | |
|---|---|
| 扩展权限 | `tabs`（标签标题 / URL）、`tabGroups`（组名）、`alarms`、`scripting` |
| 站点范围 | 只有你的 DataAgent 域名 + `127.0.0.1` |
| 读什么 | 标签标题、URL、标签组名；对有新回复的会话取一次最后一条消息，**在页面内**判断有没有「当前服务繁忙 / tpm limit」，只回「是 / 否」 |
| 不读 | 页面正文、聊天记录全文、其它网站的内容 |
| 发往 | 只有 `http://127.0.0.1:8899`，代码里没有任何外部域名 |
| 落盘 | `~/.taskpulse/`（配置、密钥、会话状态），本地磁盘，不上传 |

---

## 卸载

双击 `uninstall.command`，会结束正在运行的进程，清掉 App、历史版本留下的后台项、界面偏好。

任务历史保留在 `~/.taskpulse`；彻底清空再执行 `rm -rf ~/.taskpulse`。

浏览器扩展需要在扩展页里手动移除一次。

## 常见问题

| 现象 | 处理 |
|---|---|
| 双击脚本提示「已损坏」/「无法验证」/「来自身份不明的开发者」 | 见第二步的三种办法；最快是终端执行 `xattr -dr com.apple.quarantine . && ./install.command` |
| 终端窗口一闪而过 | 脚本执行失败。右键 → 打开，让它停住看报错 |
| 弹窗说「uv 跑不起来」 | 选「用安装包自带的」，会解压一份干净的 |
| 「依赖安装失败」 | 连上公司网络后重跑 `install.command`，已有安装不会被动 |
| 细条不见了 | 双击 `~/Applications/TaskPulse.app`（没打开就没有进程，这是预期行为） |
| 数字一直不动 | 确认浏览器里有 DataAgent 页面、扩展是启用状态；看 `~/Library/Logs/taskpulse.log` |
| 加载扩展报「清单文件缺失或不可读取」 | 选错目录了：要选 `~/Applications/TaskPulse/edge-ext`，不是解压包里那份 |
| 分组全是「未分组」 | 扩展没连上，或那些会话没有开着的标签 |
| 点任务没反应 | 系统设置 → 隐私与安全性 → 自动化，把 TaskPulse 对浏览器的开关打开 |
| 点任务跳到错误页面 | 把 `~/Library/Logs/taskpulse.log` 尾部发我，里面有 `focus_tab` / `no tab match` 的具体行 |
| 提示「N 个会话状态待确认」 | 这几个会话这一轮没取到状态，数字先别当真，下一轮会恢复 |
